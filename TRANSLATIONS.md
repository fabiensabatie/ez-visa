# EZ VISA language versions

Open `index.html` and choose a language from the header. Keep the `assets` folder beside the HTML files.

Included: English, Korean, Simplified Chinese, Hindi, Japanese, French, German, Russian, Thai and Spanish. Hindi is used for the request for an Indian language; it does not represent every language spoken in India.

Each version includes localized page content, forms, FAQs, image descriptions, titles, descriptions and business/service structured data. Language links retain the current section. Contact form service values remain stable across translations; the email draft uses the selected language.

These are initial machine-assisted translations with headline and functional checks, not a native-speaker legal review. Review visa terminology and customer-facing copy with native speakers before publication. Website languages do not imply that the agency provides spoken support in each language.

For launch, choose the live domain, set absolute canonical and alternate-language URLs, add the sitemap, and verify indexing and performance. Current alternate links point to the local HTML files. No domain or government affiliation has been invented.
