# EZ VISA

Static multilingual website for EZ VISA, Chiang Mai, Thailand.

## Preview

Open index.html directly, or serve this directory with any static web server. No build step or dependencies are required. Keep the assets directory alongside the HTML files.

## Languages

English (index.html), Korean, Simplified Chinese, Hindi, Japanese, French, German, Russian, Thai and Spanish. The header language selector preserves the current section.

## Before publishing

- Review the initial translations with native speakers, including visa terminology.
- Configure canonical URLs, absolute alternate-language URLs and a sitemap for the chosen live domain.
- Verify business details and service descriptions, and check responsive layout and accessibility in the target browsers.
- Preserve the photography attribution and license links in the footer.

The repository contains the website only; hosting and DNS are not configured by this commit.
